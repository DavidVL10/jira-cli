# jira-cli

A command-line tool for working with Jira from the terminal.

## Status

Early development — the project is just getting started. Nothing is implemented yet.

## Goals

- Browse and search issues without leaving the terminal
- View issue details, comments, and status
- Create, update, and transition issues
- Configure connection via a Jira site URL, email, and API token

## Getting Started

```bash
git clone https://github.com/DavidVL10/jira-cli.git
cd jira-cli
```

Setup and usage instructions will be added as the CLI takes shape.

## Configuration

Authentication will use a Jira API token. Generate one at
https://id.atlassian.com/manage-profile/security/api-tokens and keep it out of
version control — prefer environment variables or a local config file that is
gitignored.
